提示词不必每次从零写。把高频场景沉淀成模板，效率和稳定性都会明显提升。以下模板可直接复制到 ChatGPT、Claude、Gemini 使用。

## 使用方法

1. 复制模板  
2. 替换 `{花括号}` 中的内容  
3. 先要大纲/结构，再扩写细节  
4. 对结果不满意时，追加约束而不是整段重写

## 写作模板

### 博客成稿

```text
角色：资深科技编辑
任务：写一篇关于「{主题}」的中文博客
读者：{读者画像}
约束：
- 字数约 {字数}
- 语气专业但易懂
- 包含：引言、3 个要点、小结
- 不要编造数据；不确定处请标注
输出：Markdown
```

### 润色改写

```text
请润色以下文本：
目标风格：{正式/活泼/简洁}
保留原意，删除套话，句子更短。
先给修改后全文，再列 3 条改动说明。

原文：
{粘贴文本}
```

## 编程模板

### 代码审查

```text
你是资深{语言}工程师。请审查代码，只输出高优先级问题。
每条格式：问题 / 影响 / 修改建议（不超过 2 句）。
不要重写全部代码。

代码：
{代码}
```

### 报错诊断

```text
我遇到以下报错。请按步骤排查：
1) 最可能原因（最多 3 个）
2) 验证方法
3) 修复步骤
不要空泛建议。

环境：{系统/版本}
报错：
{错误信息}
相关代码：
{代码}
```

## 学习模板

```text
你是耐心的老师。请解释「{概念}」，面向{水平}。
结构：
1) 100 字直觉解释
2) 一个生活类比
3) 两个易错点
4) 一道自测题（含答案）
```

## 会议纪要模板

```text
请整理会议记录为：
- 决议
- 待办（负责人 + 截止日期）
- 未决问题
语气客观，不补充未出现信息。

记录：
{原文}
```

## 进阶技巧

- 给 1–2 个示例（Few-shot）比空口描述风格更稳  
- 复杂任务拆成「大纲 → 扩写 → 压缩 → 校对」  
- 需要结构化数据时，明确要求 JSON 字段
