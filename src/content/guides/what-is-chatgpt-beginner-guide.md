ChatGPT 是 OpenAI 推出的对话式 AI 产品。你可以把它理解成：**一个能读懂自然语言、并生成文本（以及部分多模态结果）的智能助手**。

## 它擅长什么

- 写作与改写：大纲、润色、翻译、总结
- 学习辅导：解释概念、出练习题、纠错
- 编程辅助：写示例、读报错、重构建议
- 头脑风暴：方案列举、角色扮演、对比分析

## 它不擅长什么

- 保证事实永远正确（可能一本正经地编造）
- 替代专业医疗 / 法律 / 财务决策
- 在未接入检索时掌握「刚刚发生」的全部实时信息

所以正确心态是：**它是加速器，不是最终责任人**。

## 10 分钟上手流程

### 1. 打开产品并进入对话

通过官方入口登录后，你会看到输入框。第一次不必追求完美提示词，先完成一轮完整对话。

### 2. 用「角色 + 任务 + 约束」提问

```text
你是高中物理老师。请用生活例子解释「加速度」，
控制在 200 字内，最后给我 1 道选择题。
```

### 3. 对结果追问，而不是重开

```text
请把刚才的解释再降低难度，并增加一个运动场景类比。
```

### 4. 让它按格式输出

```text
请用 Markdown 输出：
1) 结论
2) 三步操作
3) 常见坑
```

## 第一次就该避开的坑

| 坑 | 更好的做法 |
| --- | --- |
| 「帮我写篇文章」太笼统 | 说明主题、读者、字数、风格 |
| 一次丢给它十个目标 | 拆成多轮，先大纲后正文 |
| 盲信数字与引用 | 要求给出来源思路并人工核实 |
| 粘贴隐私数据 | 先脱敏 |

## 和 Claude、Gemini 的关系

ChatGPT 不是唯一选择。长文档可看 Claude，Google 生态协作可看 Gemini。若你还在起步期，先把 ChatGPT 的提问方法练熟，再按场景扩展。
