Claude 是 Anthropic 推出的大模型助手，中文用户常把它用在：**长文档理解、严谨改写、复杂推理与代码审查**。

## Claude 更适合什么人

- 经常处理合同、论文、纪要、PRD 等长文本
- 需要稳定、克制、少“胡说”的写作风格
- 做代码阅读、重构建议、测试用例设计

如果你主要做短对话和图像玩法，ChatGPT 可能更全能；两者可以并存。

## 5 分钟开始

直接打开 [Claude 使用入口](https://babawuai.com/products/ai-chat/claude-opus-4-8/)，用下面的首问模板开始第一轮。


1. 打开 Claude 官方产品并完成登录  
2. 上传或粘贴一段你真正在处理的材料  
3. 明确要求「先摘要，再给问题清单，再给改写」

### 推荐首问模板

```text
请阅读以下材料，输出：
1) 200 字摘要
2) 关键风险/问题列表（按优先级）
3) 可执行的下一步建议（不超过 5 条）
不要编造材料中未出现的事实。
```

## 长文本技巧

1. **先结构化，再深挖**：先要目录式摘要，再针对某一章追问  
2. **要求引用原文定位**：减少幻觉  
3. **约束口吻**：例如「保持正式、不夸张、不补未证实信息」  
4. **分角色复核**：让它先当作者，再当审稿人挑错

## 和 ChatGPT 怎么分工

| 任务 | 更建议 |
| --- | --- |
| 长文精读与风险点 | Claude |
| 多模态/图像/综合插件生态 | ChatGPT |
| 快速头脑风暴多个版本 | ChatGPT |
| 最终成稿语气统一 | Claude |

## 注意事项

- 同样不要上传高度敏感的个人信息与未公开商业机密
- 输出仍需人工确认，尤其是法律与合规相关内容
- 具体模型名称与额度以官网为准
